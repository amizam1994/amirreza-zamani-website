# Amirreza Zamani — Academic Website

This repository contains the static files for [my academic website](https://amirreza-zamani-research.melodicfir16.chatgpt.site).

Open `index.html` in a browser to view the site locally. To publish the same site with GitHub Pages, choose **Deploy from a branch** in the repository's Pages settings, then select the default branch and `/ (root)`. The files use relative asset paths so the page works at a GitHub Pages project URL.

The portrait and shield background are included with the page. The website has no build step.
